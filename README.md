# SGov FluxoSaúde - Rio Claro, RJ

Sistema de Gestão de Transporte Sanitário para a Prefeitura de Rio Claro - RJ.

## 🚀 Como conectar ao repositório GitHub

Para sincronizar este projeto com o repositório oficial (`https://github.com/Augusto8tj/SGov-FluxoSa-de.git`), execute os seguintes comandos no seu terminal:

```bash
# 1. Inicialize o git localmente (se ainda não o fez)
git init

# 2. Adicione o repositório remoto
git remote add origin https://github.com/Augusto8tj/SGov-FluxoSa-de.git

# 3. Adicione todos os arquivos ao ambiente de preparação
git add .

# 4. Crie o primeiro commit
git commit -m "Initial commit: SGov FluxoSaúde Rio Claro RJ"

# 5. Envie os arquivos para o GitHub
# Nota: Verifique se sua branch principal se chama 'main' ou 'master'
git push -u origin main
```

## 🛠 Tecnologias Utilizadas
- **Framework**: [Next.js 15](https://nextjs.org/)
- **Interface**: [React 19](https://react.dev/) + [ShadCN UI](https://ui.shadcn.com/)
- **Estilização**: [Tailwind CSS](https://tailwindcss.com/)
- **Inteligência Artificial**: [Genkit](https://firebase.google.com/docs/genkit) (Google Gemini)
- **Backend**: Firebase (Auth/Firestore)

## 📱 Módulos
- **Administrativo**: Gestão central, frotas e auditoria.
- **Portal UBS**: Solicitações e gestão de pacientes pelas unidades.
- **Módulo Motorista**: Itinerários e checklists mobile-first.
